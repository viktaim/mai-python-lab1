# toolkit

Консольная программа на Python: калькулятор арифметических выражений
и конвертер величин (длина, масса, температура). Без `eval`.

## Установка

Из папки `lab_01`:

    pip install -e .

## Использование

Калькулятор:

    python -m toolkit calc "2+3*4"        # 14.0
    python -m toolkit calc "10 / 4"       # 2.5
    python -m toolkit calc -- "-2*-3"     # 6.0

Выражения, которые начинаются с минуса, нужно передавать после `--`,
иначе `argparse` примет их за опцию.

Конвертер:

    python -m toolkit convert 1000 --from mm --to m     # 1.0
    python -m toolkit convert 100 --from c --to f       # 212.0

Поддерживаемые единицы (регистр не важен):
длина: mm, cm, m, km; масса: g, kg; температура: c, f, k.

## Как устроен калькулятор

1. `tokenize` разбивает строку на числа и операторы, унарные `+` и `-`
   сразу становятся частью числа.
2. `validate` проверяет, что числа и операторы чередуются.
3. `evaluate` считает в два прохода: сначала `*` и `/`, потом `+` и `-`.

Вычислительное ядро (`calculator.py`, `converter.py`) ничего не печатает
и не читает ввод. Ввод, вывод и коды возврата — только в `__main__.py`.

## Ошибки и коды возврата

При ошибке сообщение выводится в stderr, код возврата 2. При успехе — 0.
Ошибки: пустое выражение, некорректное выражение (в том числе недопустимый
символ и два оператора подряд), деление на ноль, неизвестная единица,
несовместимые единицы, температура ниже абсолютного нуля.
